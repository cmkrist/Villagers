# Actual local payment, productive use and clean restart

Final source passed **358 Java tests and 10 Python checks**. The final native
server run and clean restart both passed. The source snapshot at collection had
no drift from the frozen build. All217 detached main class files matched the
loaded mod JAR. Exact hashes, reports and terminal process identities are in
[results.json](results.json) and `marked-coins/`.

The ordinary controller completed this finite chain:

1. During declared initial setup, a test operator transferred four actually held,
   custom-named emerald items through four real sneak-right-click gift handoffs.
   The operator's hand emptied; no further supply was given.
2. The buyer proposed an understood trade and paid two existing marked coins for
   the seller's actual spare wooden hoe. The seller retained its iron hoe.
3. The buyer used the purchased hoe for three native wheat harvest/replants,
   paying real seeds and three durability. Three wheat funded one native bread
   recipe; the buyer ate it under ordinary metabolism.
4. Later hunger produced another local quote and acceptance. The buyer paid its
   last two coins for actual bread and ate it. The seller retained three bread
   (15nutrition) and its working tool. Coin components survived payment.
5. At tick5468, the buyer held zero coins and the seller held the same four real
   coins. Both adults were alive. The next server launch retained money, food
   inventories, meal nutrition and purchased hoe wear without another transaction
   or recipe.

Each exchange receipt proves equal buyer debit/seller credit and equal seller
item loss/buyer item gain. All three harvest receipts satisfy before + native
drops - one replanting seed = after + overflow, with one actual hoe wear each.
No charitable transfer is counted as a sale. The trade and gift notes use existing
mind persistence; physical items use native entity saving. The tests establish
clean restart, not global crash atomicity or death accounting.

This is a new supplied peaceful platform with beds, table, water, three mature
wheat plants, selected greedy/frugal seller and glutton buyer, and an explicitly
common initial language. The seller initially holds an iron hoe, a spare wooden
hoe and six bread; the buyer starts with eight seeds and receives the four marked
coins during setup. It runs80TPS with400base exhaustion/day. After setup there
are no supplies, body/clock/growth/actor-position setters or scripted exchange,
harvest, recipe or meal. It is a finite integration fixture, not normal survival,
renewable production, sustained money circulation or a complete economy.

`prototype/` retains an earlier passing plain-coin fixture with different source;
it is not final-source acceptance. `source-v4.zip`, `source-pins-v4.json` and
