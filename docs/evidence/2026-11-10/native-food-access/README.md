false. No test-only probe was installed in the playable client. Its low-health
stop was not triggered. Selected old authored-world save hashes still match.

then v6 (normal cold continuation, 406 ticks, Fern crafted and ate three bread).

the final native snapshot and process receipts are included here.

actual island farm contains 26 planted but unripe crops. Illager growth on this
